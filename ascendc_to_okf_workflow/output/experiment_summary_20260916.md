## 2. 核心验证结论

**H1（冷提取机制可重复性）：成立。** 盲提取一轮达语义完备：94 v1 卡零语义试错
（g 域 exp 直译、五步顺序、varlen/l2norm/init 全开关正确）；85 的语义层三组
最终都对（golden 兜底）。唯一 gen 损耗均为提取侧骨架一行缺陷（hv→hk、BV 守卫
写法、零初始化丢 cast——同类回归三次，已立族 §4.6 复用纪律）。

**H2（族知识摊销）：部分成立，边界精确测绘。** ✅ 避坑类资产完整迁移
（一块一 program、C-016/017、int64 纪律、AST 规避——94 全程零 UB/误编译/
勿重试违反）；❌ 性能类资产跨 kernel 结构外推失效（2048 BV 规则、整块 load
+select 在逐 token 结构上被证伪）——**族杠杆的适用范围单位是 kernel 结构，
不是算子类**（族 §4.5 已校准）。

**两轮闭环是机制的基本工作单元**：B3→B4 ×1.77（1.3251→2.3456）；
94 首轮→复跑 ×2.05（15.095→30.9029）。**纯提取（零本算子实测）从不产出高
性能**——语义层可行，性能层永远需要至少一轮实测；这不是方法缺陷，是问题
性质（性能知识的存在形式是测量，不是文档；对照：A1 也要 4 轮 opt 自发现，
template 谱系也要多会话+11 轮 opt）。

**跨谱系知识传递首次成立**：template 臂实测（BV=64、寄存器轮换 ×1.363、
WY 价值定位）经卡片文字传递后，在无 template/KB/历史经验的干净会话复现
且更优（×1.4625）——OKF 核心论点的最强证据。

**判据终局（94 预注册 5 项）**：首轮 3/5 → 复跑 **5/5**（iter_0 50/50、gen 1、
零勿重试违反、胜 naive、≥2 杠杆复现）。

## 3. 关键转折与教训（全部已立法）

1. **证据规则**（B3 翻车）：同算子实测 > 家族默认 > 跨家族外推；对旧论断的
   「修正」要求不低于原论断的证据强度（C-011 收窄）。
2. **上下文失败不得升格禁令**（B3 的 bf16x3）：失败上下文测量有毒，只标
   ⚠️ 两态（C-012 变体）。
3. **未实测参数必须标两态，不得钉死**（94 v1 的 BV=16 钉死造成 2.54x 差距
   主因之一）。
4. **[DERIVED] 定量否决权重 < 同结构实测**（94 首轮 WY 否决被 template 臂
   推翻）——卡片表述会引导 agent 决策，保守表述 = 保守决策。
5. **骨架改动适用与卡片论断相同的证据标准**（三次同类回归各耗 1 轮 gen）。
6. **第一轮的价值是「干净的测量平台」而非性能**：健康（50/50+无编译污染）
   的第一轮产出的证伪清单与差距地图必然有用；不健康的第一轮（B3）产出
   有毒知识。
7. **g 域族内不通用**（85=exp2/log2，94=自然对数 exp）——逐算子独立仲裁。

1. **mhc 剩余算子批量提取**——H1/H2 的规模化验证（族曲线：第 3 个算子的

   边际的隔离测量）。

## 6. 一句话总结

编译仓/文档仓做机制仲裁——两轮闭环在 op-85（×1.77）和 Gdn2Fwd（×2.05）
上均验证收敛，知识经卡片文字跨谱系传递复现成立；纯提取的「首轮高性能」
预期已正式放弃，提取质量的验收口径改为 iter_0/gen 轮次/勿重试违反/两态项
四项收敛指标。**
