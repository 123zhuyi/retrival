## Memory Access Optimization: block pointer abstraction

【优化维度】：访存效率
【泛化层级】：条件性（迁移条件：硬件 910b2/910b3，fp16/bf16，BLOCK_M ≥128、HEAD_DIM ≥64、SUB_BLOCK_M ≥32；失效边界：BLOCK_M 较小（<128）时 4 路子分块的调度开销大于 ILP 收益；block ptr 不支持的不规则访问模式（如 gather）不适用）

### 原则
- **block pointer abstraction**：Utilizes tl.make_block_ptr to handle 2D tensor blocks efficiently. This replaces manual pointer arithmetic, enabling the compiler to generate optimized vectorized load/store instructions and handle boundary conditions (padding) automatically.
- **sub blocking strategy**：Implements a 4-way sub-blocking strategy by dividing blockM into four SUB_BLOCK_M segments (a, b, c, d). This micro-tiling is designed to match the hardware's pipeline depth or cache line size, facilitating software pipelining and instruction-level parallelism (ILP) to hide memory latency.
- **workspace pointer preparation**：Pre-calculates and organizes pointers for four distinct workspace buffers (WS1, WS2, WS3, WS4) alongside their sub-block pointers. This offloads address calculation overhead from the main kernel loop, ensuring that intermediate storage for attention scores (QK^T) and softmax results is readily accessible.
- **layout agnostic strides**：Explicitly handles multiple stride parameters (stride_qz, stride_qh, stride_kn, etc.), allowing the kernel to support various tensor memory layouts (e.g., non-contiguous or transposed) without requiring expensive data reordering prior to the kernel launch.

### 代码/骨架出处
- `TritonPath`:
```python
raw_experiences/extracted_kernels/053-get_params.py
```

**坏实践（反例）**：手写标量指针运算 + 手动边界判断替代 `tl.make_block_ptr`
```python
offs = pid * BLOCK_M + tl.arange(0, BLOCK_M)
ptr = base + offs[:, None] * stride_m + offs_n[None, :] * stride_n
val = tl.load(ptr, mask=(offs[:, None] < M) & (offs_n[None, :] < N))  # 手动 padding
```
后果：编译器无法生成优化的向量化 load/store，边界 mask 逻辑易错且指令冗余。✅ 正解：用 `tl.make_block_ptr` 抽象 2D 块访问，边界 padding 由编译器自动处理；地址预计算移出主循环。

**已知实例**：attention §raw (`experiences/attention/exp_attn_ptr_setup_001.yaml`)
- 声称性能收益：25%
- 备注：This function serves as a pointer setup utility for 在线 Softmax 类注意力 kernel. The specific 4-way split of the M-dimension suggests a tuning for the Ascend 910B series' vector or cube unit capabilities.
