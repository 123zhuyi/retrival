## Scheduling Optimization: dynamic load balancing

【优化维度】：多核并行与负载均衡
【泛化层级】：条件性（迁移条件：硬件 910b2, 910b3, 91093, 91095；失效边界：各组 K 维差异小时动态调度与核轮转无优势；`dot_pad_only_k` 提示绑定 CANN/Triton 集成；M/N/K < 32 时 tile 过小，矩阵单元利用率低）

### 原则
- **dynamic load balancing**：The kernel implements a dynamic scheduling strategy within the main loop (`for cur_block in range(cur_block, cur_count, total_cores)`). This allows a single kernel launch to handle multiple matrix multiplications with varying M dimensions (groups), efficiently distributing work across all available cores to prevent idle time caused by uneven group sizes.
- **hardware specific hints**：Utilizes `tl.compile_hint(..., "dot_pad_only_k")` to explicitly instruct the compiler to pad operands only along the K dimension for the dot product instruction. This is critical for Ascend NPU hardware (910B series) to ensure the matrix unit (Cube) operates efficiently without unnecessary memory overhead or instruction constraints violations.
- **pointer arithmetic optimization**：Optimizes memory access patterns for the 'bNmajor' layout by calculating base pointers (`a_ptrs_base`, `b_ptrs_base`) using offsets that incorporate the group index (`group_idx`). This ensures that while iterating through the K dimension, the memory accesses remain coalesced and aligned with the hardware's expectation for grouped operations.
- **dynamic load balancing**：Implements a core rotation mechanism using modulo arithmetic on `last_count` to distribute blocks of different groups across cores. This mitigates the "tail effect" in grouped GEMMs where cores might idle waiting for the last group to finish.
- **compile hint optimization**：Utilizes `tl.compile_hint(..., "dot_pad_only_k")` to instruct the compiler backend (likely CANN for Ascend) to optimize padding specifically for the K-dimension in dot product instructions, reducing instruction overhead.
- **on chip transpose**：Performs `tl.trans(a)` immediately after loading to align the data layout for the `tl.dot` operation, ensuring efficient vectorization without requiring pre-transposed global memory layouts.

**坏实践（反例）**：对整个 tile 全维 padding 以适配矩阵单元 → M/N 维的冗余 padding 白白搬运数据 → ✅ 正解即本条：`dot_pad_only_k` 只沿 K 维 padding + 模运算核轮转消除尾部效应 + `tl.trans(a)` 片上转置对齐 dot 输入。

**已知实例**：matmul §raw (`experiences/matmul/exp_grouped_matmul_001.yaml`)
- 声称性能收益：25%
- 备注：Specifically designed for K-grouped matrix multiplication where the K dimension varies per group. The dynamic scheduling is critical for performance when group sizes vary significantly.
