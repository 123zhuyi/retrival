## Scheduling Optimization: pid grouping strategy

【优化维度】：多核并行与负载均衡
【泛化层级】：条件性（迁移条件：硬件 910b2, 910b3, 91093, 91095；失效边界：L2 带宽是瓶颈时收益最大（备注自述），算力 Bound 场景收益小；GROUP_M 取值需配合 shape，不当反而破坏局部性；EVEN_K 不成立时自动回退带 mask 路径）

### 原则
- **pid grouping strategy**：The kernel implements a program ID reordering logic based on GROUP_M. It groups consecutive M-blocks together before switching to the next N-block. This significantly enhances L2 cache data locality for matrix A, as the same tiles of A are loaded once and reused for multiple columns of B within the group.
- **register rematerialization**：To alleviate register pressure during the compute-intensive accumulation loop, the output indices (rm, rn) are not kept in registers. Instead, they are rematerialized (recalculated) just before the store phase. This frees up valuable register space for the accumulator and intermediate data blocks.
- **conditional masking**：The kernel utilizes a compile-time heuristic (EVEN_K) to optimize memory loads. When K is perfectly divisible by blockK, it bypasses mask generation and uses unmasked loads, reducing instruction overhead and improving memory bandwidth utilization.
- **strict precision enforcement**：The dot product operation explicitly sets allow_tf32=False. This ensures that the hardware does not trade numerical accuracy for speed by using lower-precision formats (like TF32), guaranteeing FP32-level precision for the accumulation.

**坏实践（反例）**：行优先发射 pid + K 整除时也生成 mask 指令 + 全程寄存器持有 rm/rn 输出索引 → L2 命中低 + 指令浪费 + 寄存器紧张 spill → ✅ 正解即本条：GROUP_M 分组重排 + EVEN_K 免 mask + 输出索引 store 前重算（rematerialization）。

**已知实例**：matmul §raw (`experiences/matmul/exp_mm_grouped_reorder_001.yaml`)
- 声称性能收益：25%
- 备注：This kernel is designed for high-performance GEMM scenarios where L2 cache bandwidth is a bottleneck. The use of libtuner and heuristics suggests it adapts block sizes dynamically.
