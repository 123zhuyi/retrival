## Compute Optimization: fused rope computation

【优化维度】：AICore 单元利用/Scalar 削减
【泛化层级】：条件性（迁移条件：硬件 910b2, 910b3；失效边界：依赖预算好的 sin/cos 系数表（备注自述）；M/N/K < 128 时 tile 配置需重调；双调用（sin/cos 分开）结构在寄存器充足时可考虑合并以省一次输入 load）

### 原则
- **fused rope computation**：Fuses the Rotary Positional Embedding (RoPE) operation directly into the matrix multiplication kernel. This eliminates the need to write intermediate rotated tensors to global memory (HBM), significantly reducing memory bandwidth consumption and latency.
- **dual path accumulation**：Separates the sine and cosine component calculations into two distinct calls to `_single_rope_matmul_kernel`. This structure allows for cleaner code generation and potentially better register pressure management by handling the two parts of the rotation formula (x*cos - y*sin) independently before accumulation.
- **dynamic block tiling**：Utilizes configurable `blockM`, `blockN`, and `blockK` sizes along with a `BLOCK_TRESHHOLD`. This enables the kernel to adapt its tiling strategy based on the specific dimensions of the input matrices (M, N, K) to optimize for the L0/L1 cache hierarchy of the NPU hardware.

### 代码/骨架出处
- `TritonPath`:
```python
raw_experiences/extracted_kernels/058-_rope_matmul_kernel.py
```

**坏实践（反例）**：RoPE 后的中间张量写回 HBM 再由 matmul kernel 读回 → 完整中间张量一次往返 → ✅ 正解即本条：旋转直接融合进矩阵乘 kernel，sin/cos 分量双路径分别累加。

**已知实例**：matmul §raw (`experiences/matmul/exp_rope_matmul_fused_001.yaml`)
- 声称性能收益：25%
- 备注：This kernel is specifically designed for Transformer inference where RoPE is applied before a projection or similar linear layer. It assumes the availability of precomputed sine/cosine coefficients.
