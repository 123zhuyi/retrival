## Compute Optimization: operator fusion

【优化维度】：AICore 单元利用/Scalar 削减
【泛化层级】：条件性（迁移条件：硬件 910b2, 910b3, 91093, 91095；失效边界：依赖 dl dialect 的 `dl.parallel` 子块划分；假设输入按两半切分（q1/q2）的布局约定，不符则失效；BLOCK_SIZE/head_dim < 64 时子块配置需重调）

### 原则
- **operator fusion**：Fuses Root Mean Square Layer Normalization (RMS Norm) and Rotary Positional Embedding (RoPE) into a single kernel. This eliminates the need to write intermediate normalized tensors to global memory (HBM), significantly reducing memory bandwidth consumption and latency.
- **sub blocking strategy**：Utilizes `dl.parallel` with a `SUB_BLK` parameter to partition the `blockSize` into smaller chunks. This fine-grained tiling improves instruction-level parallelism and register reuse, ensuring the compute pipeline remains saturated during the reduction and element-wise operations.
- **data layout optimization**：The input tensors (inputA, inputB) are split into two halves (q1/q2, k1/k2) along the head dimension. This layout is designed to align with the hardware's vector unit width (e.g., 128-bit or 256-bit loads), maximizing memory coalescing and compute throughput for the specific NPU architecture.
- **v tensor passthrough**：Includes the loading and storing of the inputC tensor within the same kernel execution. This overlaps the memory transfer latency of the inputC tensor with the compute-intensive RMS and RoPE operations on inputA and inputB, effectively hiding memory access costs.

**坏实践（反例）**：归一化与位置编码各起 kernel → 中间归一化结果写回 HBM 再读回 → ✅ 正解即本条：单 kernel 融合 + `dl.parallel` SUB_BLK 细粒度子块 + inputC 同 kernel 透传（搬运与计算重叠）。

**已知实例**：normalization §raw (`experiences/normalization/exp_rmsnorm_rope_001.yaml`)
- 声称性能收益：25%
- 备注：The kernel relies on a specific dialect (dl) for sub-blocking and assumes inputs are split into two halves (q1/q2). Ensure input tensors adhere to this layout.
